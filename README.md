# Mega Trapný

A pixel-art music video for the song **Mega Trapný**, plus a tiny mushroom picking game. Open `index.html` through any static web server (or GitHub Pages).

- `index.html` : the video player and the game page
- `game.js` : the mushroom picking game
- `song.mp3` : the song

Add `?edit` to the URL to show the section timing editor under the video.
